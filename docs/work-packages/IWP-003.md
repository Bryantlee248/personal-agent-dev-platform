# IWP-003：Paseo 本地隔离 PoC

- Roadmap：W-003
- Primary：Delivery AI
- Verifier：Independent Verification AI
- 状态：APPROVED
- 人工授权：2026-11-17 用户明确同意执行调整后的工作计划
- 目标环境：本地 Windows 电脑的独立测试目录

## 目标

验证 Paseo 是否能作为可替换执行层，稳定管理本地 Agent、独立 worktree、停止恢复和运行记录。结论只用于 PoC 选型，不构成生产就绪。

## 允许

- 在独立目录安装固定版本的 Paseo 桌面端或 CLI/daemon。
- 使用测试仓库或本项目的只读/临时 worktree。
- 复用已经配置的 Codex 第三方 Provider，但不读取或回显凭据。
- 执行无外部副作用的启动、停止、恢复、资源和 worktree 测试。
- 保存安装版本、命令输出、资源占用和清理证据到 `docs/evidence/IWP-003/`。

## 禁止

- 不连接 Paseo 官方 Hub、relay、手机或公网入口。
- 不接飞书、Slack、Discord、GitHub Webhook 或真实业务事件。
- 不创建生产凭据，不读取真实业务数据，不部署到229或生产环境。
- 不修改默认 Codex 配置，不安装未知插件，不授予 daemon 全局外部执行权限。
- 不删除 Autoloop 隔离环境，不修改229 Runner服务。

## 验收

- 版本和源码/安装来源固定，可重复确认。
- daemon仅监听本机或使用明确的本地通信方式。
- 一个只读任务和一个临时 worktree 小任务可启动、停止并读取结果。
- 重启后能说明任务和工作区如何恢复；无法恢复时必须如实报告。
- 记录空闲和单任务资源占用，不突破本地资源保护线。
- 卸载或隔离清理路径明确，不影响现有Codex和Autoloop。
- Independent Verification AI复核证据后，才能关闭W-003。

## 停止条件

- 安装要求关闭安全控制、写入生产凭据或开放公网。
- 需要访问默认 Agent 密钥、真实数据或未授权外部系统。
- 空闲占用或单任务占用触发项目资源保护线。
- 同一安装/启动方法连续失败两次，先重新核对版本、文档和假设。
