# IWP-008：GitHub PR 交付契约与检查闭环

- Roadmap：W-006
- Primary：Delivery AI
- Verifier：Independent Verification AI（Qwen 只读）
- 状态：BLOCKED
- 人工授权：2026-11-18 用户明确“同意”继续下一阶段

## 已确认前置事实

- 仓库 `Bryantlee248/personal-agent-dev-platform` 为私有仓库，当前身份有 admin 权限。
- GitHub branch protection 与 repository rulesets API 均返回 403：当前套餐需升级 GitHub Pro 或将仓库公开后才能启用。
- 用户没有授权付费升级或公开仓库，因此本工作包不得执行这两种操作。

## 目标

建立不依赖具体 Agent 的 PR 交付契约：PR 必须绑定角色、IWP、固定 head SHA、授权写路径、检查结果和审查账本。GitHub Actions 可确定性验证契约，但在当前套餐下不能声称 required checks 已机械阻止合并。

## 允许

- 增加 PR 模板、零依赖交付契约校验器、失败关闭测试和 GitHub Actions 检查。
- 用测试 fixture 演练绿灯、红灯、SHA 漂移、角色/路径越权和缺失审查账本。
- 创建隔离测试分支和 PR 来验证检查运行；测试 PR 不得合并。
- Qwen 最多两轮只读复核；229 Runner 执行确定性 CI。

## 禁止

- 不自动合并、发布、部署，不启用 auto-merge，不绕过检查。
- 不公开仓库、不购买或升级套餐、不创建 token、App、webhook 或长期凭据。
- 不把普通 CI 成功、PR 模板或人工约定表述为 branch protection。
- 不修改 Issue、发送外部消息或关闭 W-006，除非完整验收证据支持。

## 验收

- PR 契约绑定固定 head SHA、IWP、角色、授权路径、检查和审查账本。
- 非固定 SHA、缺字段、越权路径、红灯检查、失败/缺失复核均失败关闭。
- GitHub Actions 在真实 PR 上运行交付契约检查。
- branch protection 能在真实红灯 PR 上机械阻止合并，且 merge 仍需 Human 授权。

## 预期结论

- 当前可完成前三项的实现和验证。
- 最后一项受 GitHub 私有仓库套餐能力阻断；在套餐或仓库可见性不变时，W-006 应落为 `BLOCKED / HUMAN_ACTION_REQUIRED`，不得标记 DONE。

## 停止条件

- 需要付费升级、公开仓库、新凭据、自动合并、发布或部署。
- 两轮独立复核后仍有实质缺陷。
