# IWP-009：公开仓库分支保护与 Delivery Contract 收敛

- Roadmap：W-006
- Primary：Architecture AI（治理）；Delivery AI（受限实现）
- Verifier：Independent Verification AI（Qwen 只读）
- 状态：ACTIVE
- 人工授权：2026-11-18 用户明确选择公开仓库，并同意继续治理修复和门禁内合并

## 目标

在已公开仓库上完成 W-006：让 Delivery Contract 对治理类 PR 安全返回 `not-applicable`，对 Delivery PR 继续严格验证；将其加入 `master` required checks，并用绿灯与红灯 PR 证明机械门禁。

## 已完成前置条件

- 公开前扫描当前树、全部 Git patch、历史对象、Issue 和 PR，未发现真实凭据、私有数据或大文件。
- 仓库已改为 PUBLIC。
- `master` 已启用 strict required checks、管理员强制、禁止 force-push/删除和 conversation resolution。
- PR #12 已证明红色 Governance 检查使 GitHub 返回 `mergeStateStatus: BLOCKED`，且未合并。

## 允许

- Architecture 同步 PROJECT/ROADMAP/DECISIONS/WORKLOG、工作包和证据。
- Delivery 仅修改 Delivery Contract 校验器、workflow、对应 e2e 与 package script。
- 创建、验证并在全部 required checks 通过后合并本工作包的治理/实现 PR。
- 将 `Validate fixed-SHA PR contract` 加入 required checks，并做一次红灯阻断复验。

## 禁止

- 不进入 W-007，不发布、不部署、不启用 auto-merge。
- 不降低现有 Governance/CI 门，不关闭管理员保护，不允许 force-push 或删除 master。
- 非 Delivery PR 只能在实际 diff 完全属于 Architecture ownership 时返回 not-applicable；不得用 PR body 自声明绕过。
- Delivery PR 仍必须从可信 base 读取 ACTIVE IWP ownership，并绑定固定 head SHA 和 Verification 账本。

## 验收

- 治理类 PR 的 Delivery Contract 返回 `not-applicable` 且其他治理门通过。
- Delivery PR 的合法/非法路径、SHA 和复核账本仍分别通过/拒绝。
- 五项 required checks 均配置到 master 且 enforce_admins=true。
- 真实红灯 PR 的 `mergeStateStatus=BLOCKED`；测试 PR 均关闭或按授权合并，无遗留分支。

## 停止条件

- 需要弱化现有保护、管理员绕过、自动合并、发布或部署。
- 两轮独立复核后仍有实质缺陷。
