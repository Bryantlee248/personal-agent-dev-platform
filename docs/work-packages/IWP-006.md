# IWP-006：固定策略接力契约

- Roadmap：W-010
- Primary：Delivery AI
- Verifier：Independent Verification AI（Qwen 只读）
- 状态：CLOSED
- 人工授权：2026-11-18 用户明确同意按重新设计方案执行

## 目标

重建有人在场的结构化接力校验器，消除 IWP-005 的自授权缺陷。接力单的权限和命令
必须来自 `fixed_sha` 中的 `PROJECT.json` 与 `contracts/handoff-policy.json`。

## 设计约束

- 接力单只携带 `command_ids`，不接受自由文本命令。
- 写路径必须经过跨平台规范化，并与固定策略中的条目精确匹配；不接受父目录或子目录扩大。
- 固定 SHA 必须解析为本仓库 commit；授权、ownership 和策略都从该 commit 读取。
- Verification/Human 不得获得写路径。
- 校验器只输出经策略解析的命令 argv，不执行命令、不创建工作树、不启动 Agent。
- 路径拒绝绝对路径、盘符、UNC、空段、`.`、`..`、NUL、冒号、尾随点/空格和 Windows 保留设备名。

## 允许

- 实现 `ops/handoff-runtime` 零依赖校验器和说明。
- 测试合法接力及固定 SHA、路径、角色、command ID、秘密、畸形输入、低内存和并发失败关闭。
- Qwen 最多两轮只读复核；229 Runner 执行确定性 CI。

## 禁止

- 不修改 `contracts/handoff-policy.json` 以迁就实现。
- 不执行接力单中的命令，不创建真实 worktree，不自动启动 Agent、合并或部署。
- 不接外部通道、真实数据或新增凭据。

## 验收

- 策略、IWP 和 ownership 均从同一个固定 SHA 读取并一致。
- 自由文本命令、未知 command ID、非精确路径和 Windows 特殊路径均拒绝。
- 两轮内独立复核无实质缺陷；本地及 229 全部门禁通过。

## 停止条件

- 两轮独立复核后仍有实质缺陷。
- 需要执行命令、扩大权限、修改可信策略、部署或真实凭据。
