## Edge Cases（边界与异常）
- 本地 Worker 断线时任务留在队列，不重复执行已确认的副作用。
- 同一事件重复到达时只处理一次。
- Agent 会话无法恢复时依据当前权威事实继续，不重做已经完成的外部动作。
- CI、GitHub 或模型服务暂时失败时按上限退避，超过上限交回人工。
- 低内存、低磁盘或重任务锁被占用时不启动新重任务。

## Non-goals（明确不做）
- 多人、多团队、多租户和企业身份平台。
- 本地大模型、GPU 集群、Kubernetes、LangGraph、Temporal 或单独任务数据库。
- 无人批准的生产部署、真实数据操作和对外消息发送。
- 用 Agent 审查取代确定性测试、required checks 或真人 UAT。
